# 镜中世界 · 线上画廊

## 文件清单（3个文件，全部上传到 GitHub 仓库根目录）

| 文件 | 说明 |
|------|------|
| `index.html` | 主页面（首页 + 展览详情 + 后台管理 + 全部逻辑） |

## 功能一览

### 前台
- 首页：Hero + 4个展览卡片 + 专栏列表 + 策展人展示
- 展览详情：点击卡片进入，按组照展示，点击图片开灯箱
- 灯箱：左右箭头/键盘方向键翻页

### 后台
- 📊 总览：展览数/作品数/总浏览/存储/专栏/策展人/自定义字体统计 + 柱状图
- 📂 展览：新增/删除展览，每个展览独立设置背景板颜色+标题字体+正文字体
- 📝 专栏：新增/删除文章
- 👤 策展人：新增/删除/编辑（弹窗编辑写真+姓名+头衔+履历）
- 🖼 上传：批量选图（拖拽/Cmd多选）→ 选展览 → 填组照标题 → 上传
- 🎨 外观设置：
  - 背景颜色/图片（实时预览 + 暗化滑块）
  - 背景板颜色（预设色板 + 自定义 + 横竖展板预览）
  - 标题字体 / 正文字体 / 策展人字体（字体卡片即时预览）
  - 自定义字体（批量上传 .ttf/.otf/.woff/.woff2，自动注册）
- ⚙ 设置：导出 data.json / 导入备份 / 导出 theme.json / 修改密码 / 重置浏览量

## 更新流程

1. 在后台操作（上传作品/修改文案/改样式）
2. ⚙ 设置 → 导出全部数据 → 保存 `data.json`
3. 🎨 外观 → ⚙ 设置 → 导出外观配置 → 保存 `theme.json`
4. 把 `data.json` 和 `theme.json` 上传到 GitHub 覆盖旧文件
5. 等 1 分钟 → 刷新网站

## 注意事项

- 图片建议单张 < 20MB，系统自动压缩到约 1MB
- 字体文件建议 < 10MB/个
- 数据存在浏览器 localStorage，清缓存会丢失，务必定期导出备份
- 浏览量统计存在访客本地，仅作参考
