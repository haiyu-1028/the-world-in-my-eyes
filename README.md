# 镜中世界 · 线上画廊

深绿 × 克莱因蓝主题的摄影展览平台，单页应用，零依赖。

## 文件说明

| 文件 | 用途 |
|------|------|
| `index.html` | 主程序（前台浏览 + 后台管理，所有 CSS/JS 内联） |
| `data.json` | 数据：展览 / 组照 / 作品 / 专栏 / 策展人 |
| `theme.json` | 外观：背景 / 字体 / 背景板颜色 |
| `.nojekyll` | 告诉 GitHub Pages 不要启用 Jekyll |

## 部署到 GitHub Pages（5 分钟）

1. 在 GitHub 上**新建仓库**，名字随便（建议 `the-world-in-my-eyes`）
2. 把下面 4 个文件**一起拖进仓库根目录**（不要放子文件夹）：
   - `index.html`
   - `data.json`
   - `theme.json`
   - `.nojekyll`
3. 点 **Commit changes**
4. 进 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / Folder: **/ (root)**
   - 点 **Save**
5. 等 1-3 分钟
6. 访问 `https://你的用户名.github.io/仓库名/`

> ⚠️ 仓库必须是 **Public**；如果是 Private，免费版 Pages 不生效。

## 后台功能清单

| 模块 | 功能 |
|------|------|
| 📊 总览 | 展览数 / 作品数 / 总浏览量 / 各展览柱状图 |
| 📂 展览 | 新增/删除展览、每展览独立设置背景板颜色+标题字体+正文字体、组照管理 |
| 📝 专栏 | 新增/删除文章 |

| 🎨 外观 | 背景颜色、背景板颜色、标题/正文/策展人字体、自定义字体批量上传 |
| ⚙ 设置 | 导出/导入数据、导出外观、修改密码、重置浏览量 |

## 字体上传闭环（重要！）

1. 后台 → 🎨 外观 → 自定义字体 → 选文件（可多选）
2. 上传成功 → 字体立刻生效
3. **点 ⚙ 设置 → 📤 导出外观 (theme.json)**
4. 把下载的 `theme.json` 传回 GitHub 覆盖旧的
5. 等 1 分钟，强刷（Cmd+Shift+R）

> ⚠️ 字体 base64 数据只存在浏览器 localStorage，不导出来传回 GitHub 就等于没传。

## 日常更新流程

1. 后台改内容 / 上传作品
2. ⚙ 设置 → 📤 导出数据 → 下载 `data.json`
3. 把 `data.json` 传回 GitHub 覆盖旧的
4. 等 1 分钟，强刷

## 注意事项

- 清除浏览器缓存会丢失所有未导出的数据
- 单张图片 ≤ 20MB，上传后自动压缩到 ~1MB
- 字体文件建议 ≤ 500KB（用 woff2 子集化工具压缩）
- localStorage 总容量约 5MB，字体多了会满
- 退出登录用相对路径 `./`，不会跳到 404

## 故障排查

| 现象 | 解决 |
|------|------|
| 打开是 404 | 确认网址带 `/仓库名/` 后缀；Settings→Pages 确认 main + /(root) |
| 页面空白 | `Cmd+Shift+R` 强刷；检查仓库根目录有 `index.html`（全小写） |
| 上传字体没反应 | 上传后必须点「导出外观」→ 传回 GitHub |
| 别人看不到作品 | 你上传的数据只在浏览器，必须导出 data.json 传 GitHub |
| Safari 打不开 | 换 Chrome 试；检查 DNS 是否屏蔽 github.io |
