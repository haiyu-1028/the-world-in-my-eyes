# 镜中世界 · 线上画廊

## 部署方法

1. 把这 5 个文件一起上传到 GitHub 仓库根目录：
   - `index.html`
   - `data.json`
   - `theme.json`
   - `.nojekyll`
   - `README.md`

2. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save

3. 等 1-2 分钟，访问 `https://你的用户名.github.io/仓库名/`

### 上传照片流程
1. 后台 → 🖼 上传 → 选展览 → 填组照标题
2. 点虚线框或"选择图片文件"按钮 → 选图片（可多选）
3. 点"上传并保存组照" → 照片暂存到浏览器
4. **继续编辑其他内容**（改策展人、改外观、加专栏…）
5. 全部改完后 → 后台 → ⚙ 设置 → 点"导出数据 (data.json)"
6. 把下载的 `data.json` 上传到 GitHub 覆盖旧的
7. 等 1 分钟，刷新网站 → 照片出现了

### 重要提醒
- GitHub Pages 是静态托管，**浏览器里的数据不会自动同步到服务器**
- 每次修改后**必须手动导出 data.json 并上传到 GitHub**
- 顶部蓝色状态条会提醒你"有未导出的修改"
- 建议定期备份 data.json 到电脑硬盘

### 外观设置
- 背景颜色：实时预览，改完点"保存外观"
- 背景板颜色：每个展览独立设置
- 字体：标题/正文/策展人 三个独立选择器
- 自定义字体：上传 .ttf/.otf/.woff/.woff2 → 自动注册 → 在下拉列表选用

## 常见问题

**Q: 上传照片后没反应？**
A: 照片暂存在浏览器内存，不会立刻显示。去"设置"导出 data.json，上传到 GitHub，刷新即可。

**Q: 导出 data.json 后网站还是没变化？**
A: 等 1-2 分钟让 GitHub 同步。然后用无痕窗口访问，或 Cmd+Shift+R 强刷。

**Q: 别人能看到我上传的作品吗？**
A: 只有你导出了 data.json 并上传到 GitHub 后，别人才能看到。

**Q: 清了浏览器缓存，数据会丢吗？**
A: 会。所以每次修改后一定要导出 data.json 备份到电脑。
