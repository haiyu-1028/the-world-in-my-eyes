## 性能与体验特性

### 📷 图片处理
- 支持上传 **最大 12MB** 的原始图片
- 前端自动 **Canvas 降采样**（最长边 2400px）+ JPEG 压缩（质量 0.88）
- 自动保证单张存储 < 1MB，不卡浏览器
- 上传进度实时显示（尺寸 / 压缩后大小）

### ⚡ 流畅度优化
- **IntersectionObserver 懒加载**：图片进入视口才加载，首屏极快
- **入场揭示动画**：滚动到才触发 fade-in，配合 `prefers-reduced-motion`
- **硬件加速**：卡片 `will-change: transform`，动画不卡顿
- **防抖保存**：策展人信息输入停止 300ms 后自动保存
- **Tab 平滑切换**：opacity 过渡，不闪屏
- **Toast 轻提示**：操作反馈不打断流程，2.2 秒自动消失

### 📱 移动端
- 触摸滑动关闭弹窗（右滑 / 下滑）
- 灯箱左右箭头切换大图 + 键盘方向键
- `-webkit-overflow-scrolling: touch` 弹性滚动
- 响应式断点 900px

### ⌨️ 键盘操作
- `Esc` — 关闭任意弹窗
- `←` `→` — 灯箱内切换上一张/下一张

## 两套界面

### 游客浏览
- Hero 首屏 → 展览卡片墙 → 文字专栏 → 策展人
- 点击展览卡片 → 弹窗查看策展陈述 + 作品
- 点击作品图片 → **大图灯箱**（可左右切换浏览全部作品）
- 点击专栏文章 → 弹窗阅读全文
- 导航栏自动高亮当前阅读位置

### 内部人员管理后台
| 模块 | 功能 |
|------|------|
| 展览管理 | 新增 / 编辑 / 删除展览 |
| 专栏管理 | 新增 / 编辑 / 删除专栏文章 |
| 策展人 | 编辑信息（防抖自动保存） |
| 上传作品 | 选展览 → 填信息 → 选图 → 自动压缩 → 上传 |
| 备份设置 | 导出 / 导入 JSON 备份 / 修改密码 |

---

## 注意事项

- 数据保存在浏览器 `localStorage`，定期导出备份
- 图片经压缩后单张 < 1MB，可放心大量上传
- 推荐使用 Chrome / Edge / Firefox 最新版
