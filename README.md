# 镜中世界 · 线上画廊

## 文件
- `index.html` — 主程序
- `data.json` — 数据（展览/专栏/策展人）
- `theme.json` — 外观配置（字体/背景/颜色）

## 部署
三个文件放 GitHub 仓库根目录 → Settings → Pages → Deploy from a branch → main / root → Save

## 外观设置子页面
| 子页面 | 功能 | 实时预览 |
|--------|------|----------|
| 背景颜色/图片 | 纯色或上传背景图 + 暗化遮罩 | ✅ 滑块/取色实时变 |
| 背景板颜色 | 照片展板颜色，10 预设 + 自由选 | ✅ 下方展板即时变 |
| 标题字体 | Hero/展览/章节标题 | ✅ 全站标题即时变 |
| 正文字体 | 专栏/策展陈述/说明 | ✅ 全站正文即时变 |
| 策展人字体 | 策展人姓名/头衔 | ✅ 全站策展人区即时变 |
| 自定义字体 | 上传 .ttf/.otf/.woff/.woff2 | 上传后出现在字体列表 |

## 更新流程
1. 后台改完 → 点对应页面「💾 保存」
2. ⚙ 设置 → 导出 data.json + theme.json
3. 上传覆盖 GitHub 上两个 json
4. 等 1 分钟，别人刷新即见
